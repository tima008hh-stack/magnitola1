КАК ПОЛУЧИТЬ APK (без Android Studio)
1. Создай репозиторий на github.com, загрузи в него всё содержимое этой папки (включая .github).
2. Вкладка Actions → build-apk → дождись зелёной галочки → внизу скачай Magnitola-apk (внутри app-debug.apk).
Или: открой папку в Android Studio → Build → Build APK(s).

УСТАНОВКА НА МАГНИТОЛУ
1. Скинь app-debug.apk на флешку, открой на магнитоле и установи (разреши установку из неизвестных источников).
2. Нажми Home → появится выбор оболочки: «Магнитола» + старый лаунчер. «Всегда» — сделать основной, «Только сейчас» — на пробу.
3. Разреши геолокацию и микрофон (микрофон нужен только для волны под бит, звук не записывается).
4. Разреши «Доступ к уведомлениям» для «Магнитола» (откроется само) — тогда видны обложка и название из любого плеера.
Вернуть старую оболочку: Настройки → Приложения → Магнитола → «Открывать по умолчанию» → очистить, или нажать Home и выбрать старый лаунчер.
